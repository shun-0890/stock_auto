# 詳細調査レポート：4441 トビラシステムズ（2026-07-24）

## エグゼクティブサマリー

**忖度なしの評価：「データモートは本物だが、現時点での投資妙味は限定的」**

3.5億件超の不審電話番号データベースという参入障壁は日本随一であり、3大キャリアとのAPI連携による収益の堅牢性は疑いない。ソリューション事業（トビラフォン Cloud / Biz）が前年比+60%超で急成長し、中期経営計画2028（売上60億円）に向けた第2の柱形成が加速している点も評価できる。しかし、FY2026通期での意図的な利益率急落（OPM 32%→23%）と、足元のリスクオフ相場（日経 -2.73%、グロース株逆風）が重なる局面で、株価は年初来高値圏（1,617円）にある。押し目なき高値圏でのエントリーは勧め難い。構造的成長ストーリーは本物だが、現在の相場環境・株価水準を踏まえれば分割エントリーで対応し、押し目を待つのが最善である。

## 2. 事業概要と競合優位性

- **セキュリティ事業（売上構成比 FY2025：約68%）**：迷惑電話・フィッシング詐欺対策データベースをNTTドコモ・ソフトバンク・KDDIにAPI連携提供。3大キャリアの迷惑電話フィルタ機能の基幹インフラとして組み込み済みで、スイッチングコストが極めて高い。国際電話番号を悪用した詐欺電話が前月比+11.4%増（2026年4月）と需要は構造的増加中
- **ソリューション事業（同：約32%、FY2025比+60.1%）**：「トビラフォン Biz」（ビジネスフォン）と「トビラフォン Cloud」（クラウドPBX、迷惑電話AI判定付き）を展開。2025年10月に施行の「カスタマーハラスメント防止対策義務化」が法人向け電話セキュリティ需要の直接的な政策的追い風
- **新規事業**：2025年10月期に法人向け詐欺メール・SMS訓練サービス「サギトレ」をリリース。フィッシング対策の訓練市場という隣接領域への展開
- **競合優位性の核心**：直接競合は事実上不在。RevCommのMiiTel（音声AI解析）やHENNGEなどとは一部機能が重複するが、「特殊詐欺対策データベース×キャリア組み込み」という立ち位置に同等の競合は存在しない。総務省・警察庁との連携による公的権威性も参入障壁を高める
- **顧客基盤の質**：NTTドコモ・ソフトバンク・KDDI（3大キャリア）という最上位顧客と長期APIライセンス契約。法人顧客は中小企業から大企業まで分散展開中

- **財務の健全性**：有利子負債ほぼゼロの実質無借金経営。現預金は2026/10期H1末で約18億円を保有。フリーキャッシュフローは年間5〜7億円水準と推定

## 4. 成長ドライバーの検証

- **カスタマーハラスメント防止対策義務化（2025年10月施行）**：労働施策総合推進法改正により、企業への対策義務化が法定化。電話窓口でのカスハラ対策として「トビラフォン Biz」「トビラフォン Cloud」の需要が構造的に拡大。H1 FY2026の法人向け+69%はこの政策的追い風を反映
- **総務省のフィッシング対策強化方針**：国際電話番号を悪用した詐欺電話が急増（前月比+11.4%）しており、規制当局の対策強化が継続。これはセキュリティ事業の安定的な義務的需要を創出する
- **中期経営計画2028の目標と達成可能性**：2028年10月期目標 売上60億円（FY2025比2.1倍、CAGR +28.8%）、営業利益17億円、ROE22%以上。達成の核心はソリューション事業が引き続き年率40〜60%成長を維持できるかどうか。H1 FY2026の+69%は現時点では目標線上。ただし比較基準が低いため、成長率の自然的鈍化には留意が必要
- **新規事業「サギトレ」**：法人向けフィッシング訓練市場は日本でもKnowBe4等の海外製品が先行するが、日本語対応・特殊詐欺特化のローカルSaaSとして差別化余地あり。短期的な業績インパクトは軽微だが、セキュリティ×法人展開の布石
- **直近ニュース**：2026年4〜5月に「特殊詐欺・フィッシング詐欺レポート」を月次開示し、データの権威性をPR。2026年6月10日にH1 FY2026決算発表。6月2日の年初来安値1,060円から7月23日の1,620円まで約+52.8%の急騰は、カスハラ法施行＋H1好決算の再評価

## 5. リスク分析

- **最大のダウンサイドシナリオ**：ソリューション事業の成長が早期に鈍化し、FY2028売上60億円目標の未達が確定した場合。先行投資で拡大した固定費（人件費）がOPM 20%以下の低収益構造を常態化させるリスク。現在の高PER（約25-28倍）は成長継続を折り込んでいるため、成長鈍化時の株価下落幅は大きい（-30〜40%）
- **キャリア集中リスク**：セキュリティ事業の収益の大部分がNTTドコモ・ソフトバンク・KDDI の3社。うち1社でも契約条件変更・内製化を進めた場合の収益インパクトが甚大。ただしスイッチングコストと3社拮抗によるロックイン効果から近中期の現実的リスクは低い
- **電話メディアの長期縮小**：固定電話・ガラケーの使用量は長期的な構造的縮小。法人向けクラウドPBXへの転換を急ぐのはこのリスクへの対応でもあるが、転換の速度次第では主力事業の頭打ちが早期に来る可能性
- **マクロリスク**：本日（7/24）の市場環境はリスクオフ（日経 -2.73%、AI・テック売り優勢）。米10年債利回り4.63〜4.71%の高水準維持でグロース株のバリュエーション圧縮圧力が継続中。中東情勢悪化による原油高→インフレ→金利上昇という連鎖が小型グロース株の最大の外部リスク
- **競合の新規参入**：現時点では直接競合は不在だが、HENNGE・SOMPOなどセキュリティ大手の隣接領域進出、または海外のTelco Security企業の日本市場参入リスクは中長期的に存在

## 投資判断

- **推奨：条件付き買い（現値での即時フル投入は回避）**
- **エントリータイミング：**
  - 現在株価は年初来高値圏（1,617円）かつリスクオフ相場の初日。即時全力購入は避ける
  - Phase 1（押し目待ち）：1,430〜1,450円台まで下落した際に予算の1/3を買い。マクロ環境が安定しているかを確認してから
  - Phase 2（中段押し）：1,300〜1,350円台に調整局面が来た際に追加1/3を買い
  - Phase 3（FY2026 Q3決算確認後）：2027年3月頃の第3四半期決算でソリューション事業成長率の持続が確認できれば残り1/3を追加
  - 買い増しのタイミング：ソリューション事業売上が前年同期比50%以上成長を3四半期連続で確認できた段階でポジション拡大
- **推奨ポジション：ポートフォリオの4%（法人展開の成長確認後に最大7%まで引き上げ検討）**
- **目標株価（12〜24ヶ月）：**
  - 保守：1,375円（下値サポート確認用の最低ライン）
  - 中立：2,100円（中計線上進捗で自然な評価改善）
  - 強気：3,090円（2028年10月期中計完全達成シナリオ）
- **損切りライン：1,100円**（年初来安値1,060円の上方バッファ付き。これを割れた場合はソリューション事業の成長失速を疑う水準）
- **注視トリガー（時系列順）：**
  - 2026年8月頃：FY2026 Q3決算（来期は11月）→ソリューション事業前年比50%以上維持か確認
  - 2026年9〜10月：カスハラ対策需要の季節的上乗せ（法施行1周年）関連受注・報道
  - 2026年11〜12月：FY2026 通期決算→営業利益7.85億円（予想）達成可否。達成か上回れば強気シグナル
  - 2027年1月頃：FY2027 業績予想の開示内容（特に先行投資終了後の利益回復見通し）
  - 2027年中：トビラフォン Cloud 課金ID数の非公開情報から見える解約率・ARR成長
  - 2028年10月期：中期経営計画2028の最終年度。売上60億円・OPM28%以上が確認できれば目標株価3,000円超のシナリオ現実化
